SMS API Configuration

Connect any HTTP-based SMS gateway (Twilio, local Pakistani providers, custom microservices, etc.). The tool will replace {{phone}} and {{message}} in your body template.

Example: {"Authorization": "Bearer YOUR_TOKEN", "Content-Type": "application/json"}
Use {{phone}} and {{message}}. JSON example: {"to": "{{phone}}", "text": "{{message}}", "from": "MYBRAND"}
Common Providers (examples)
  • Twilio: POST https://api.twilio.com/2010-04-01/Accounts/{SID}/Messages.json with Basic Auth + form body.
  • Generic JSON API: Most modern gateways accept JSON with to + message.
  • Local / on-prem SMS modem gateways that expose HTTP are fully supported.
